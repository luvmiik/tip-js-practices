## Запуск

Команды Node.js выполняются из корня репозитория:

```bash
node practice-01/js/hello.js
node practice-01/js/types.js
node practice-01/js/progress.js
node practice-01/js/plan.js
node practice-01/js/debug.js
```

Запуск в браузере:

1. Открыть `practice-01/index.html`.
2. В теге `script` указать нужный файл, например `./js/types.js`.
3. Сохранить изменения и перезагрузить страницу.
4. Открыть DevTools → Console и посмотреть вывод.

Все пять файлов запускаются в обоих окружениях. Различие `typeof document` в задании 1 ожидаемо.

## Отладка

Исходный вывод (до исправления):

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

Вывод после исправления:

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `completedTotal` равно `"32"` (string), `remainingTasks` равно -24 | Конкатенация строк `"3" + "2"` вместо сложения чисел | `Number(...)` для исходных строк | Выполнено: 5, Осталось: 3 |
| Граница цикла | `controlSum` равно 6, значение 4 не учтено | Условие `taskNumber < 4` обрывает цикл на 3 | Условие `taskNumber <= 4` | Контрольная сумма: 10 |
